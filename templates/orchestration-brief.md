# 主会话统筹简报模板

把下面三行发给启用了 `$mc-plan-orchestrator` 的主会话即可。只有“目标”必填；其余信息会从 Foundation 和 Git 当前状态补全。

```text
目标：<想让哪个项目完成什么结果>
工具/模型：<Codex、ChatGPT Work、Codely/GLM-5.3 或不限>
限制：<例如仅本地提交、不部署、优先修复未完成工作；可省略>
```

最简示例：

```text
用 Codely/GLM-5.3 继续开发 Skin，生成可直接发送的提示词。
```

主会话应先核对当前方向、活动工作流、仓库锁和 Git 状态，然后返回当前事实、统筹判断、建议顺序、一份可复制提示词和完成后的回收条件。生成提示词本身不会创建分支、接管工作流或向其他会话发消息；如需主会话直接执行这些动作，请在目标中明确授权。

其他会话完成后，把它的完整回复交回主会话，并补一句：

```text
核实这份完成报告与本地 Git/工作流记录是否一致，并安排下一步。
```

主会话会分别判断实现、验证、工作流关闭、本地 `main` 集成和整体里程碑是否完成，不会仅凭“已完成”文字直接放行。
