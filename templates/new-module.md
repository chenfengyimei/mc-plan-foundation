# 新业务模块准入模板

新模块进入 MC Plan 前必须回答：

1. 用户问题、成功标准和首个纵向链路是什么？
2. 模块拥有和明确不拥有哪些数据？
3. 能否在不连接 Core/Community 的情况下完成其声明的独立功能？
4. 接入官方生态需要哪些 OIDC scope、API、事件和 SDK？
5. 是否需要新增 Resource type；其元数据 Schema 与版本策略是什么？
6. 生成或处理成本如何计量、限额和审计？
7. 隐私、许可、内容安全和未成年人风险是什么？
8. 部署、监控、备份、回退和维护 Owner 是谁？
9. 哪些事实仍未知，最迟在哪个里程碑决策？

未回答这些问题不得复制 Skin 项目结构并宣称完成架构设计。
