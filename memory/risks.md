# 跨项目风险登记

| ID | 风险 | 影响 | 当前控制 | Owner/决策点 |
|---|---|---|---|---|
| R-001 | AI 提供商无法稳定生成有效 64×64 皮肤 | 核心体验失败、成本浪费 | 提供商适配器、有效率基准、结构校验 | Skin；F3 前形成 ADR |
| R-002 | 自定义作品许可不可执行或与模型条款冲突 | 下载者和作者权利不清 | 只写政策，正式上线前法律审核 | Foundation；F6 门槛 |
| R-003 | 积分和贡献奖励被自动化滥用 | 成本与社区质量失控 | 不可变账本、幂等、限额、人工可追溯规则 | Core/Community；F1-F4 |
| R-004 | 多仓接口漂移 | 集成失败、第三方不可用 | Contracts 先行、SDK、契约测试和兼容矩阵 | Contracts；每次公共变更 |
| R-005 | 单机故障造成数据损失 | 服务中断、用户内容丢失 | 外置 COS、离机备份、恢复演练与迁移路径 | Ops；公开测试前 |
| R-006 | 完整社区范围推迟首发 | 长期无正式版本 | 分阶段保持可运行，明确 V1 门槛 | Foundation；每个里程碑评审 |
| R-007 | 身份停用、重绑或 IdP 迁移错误合并账号 | 越权、账号接管、跨服务引用失效 | ADR-0008、禁止邮箱自动合并、显式迁移、会话撤销与不可变审计 | Core/Security；IdentityLink 持久化前威胁模型与并发测试 |
| R-008 | 额度/账本并发或重试产生双扣、超发或投影漂移 | 用户资产错误、成本和信任损失 | 数据库唯一约束/锁、请求指纹、单事务账本+outbox、核对告警 | Core；首次消费接口预发布前故障与并发测试 |
| R-009 | 迁移、备份和恢复只验证任务成功 | 恢复后身份、撤销、余额或事件状态不一致 | 受控迁移、隔离恢复、余额核对、撤销/删除重放和写流量门槛 | Core/Ops；首个预发布环境验收前 |
| R-010 | JWKS、日志或健康探针暴露秘密或形成错误可用性判断 | 认证绕过、信息泄露、重启风暴 | issuer/audience allowlist、失败关闭、日志脱敏、liveness/readiness 分离 | Core/Ops；第一 Core 切片验收 |
