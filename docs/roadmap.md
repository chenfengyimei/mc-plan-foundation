# 路线图

## F0 — Foundation v1.0

建立六仓、宪法、架构、标准、ADR、Contracts 骨架、Ops 方案和协作 Skill。验收结果是决策完整、链接有效、无业务代码。

## F1 — Identity 与 Core 最小闭环

部署 Keycloak，完成内部用户映射、公开资料、开发者应用、scope、每日额度、积分账本和审计。发布 Core v1 契约与 TypeScript SDK。

## F2 — Community 资源发布闭环

完成上传会话、文件校验、通用资源模型、皮肤类型 Schema、机器审核、发布、详情、下载、作者页和删除保留流程。

## F3 — Skin 纵向链路

完成对话、提供商适配器、候选预览、Java 64×64 验证、Official/Standalone 模式、额度消费和自动发布。形成第一个端到端可用版本。

## F4 — 完整社区

依次交付搜索与标签、点赞收藏、评论、关注、信息流、规则推荐、排行、站内通知、举报、处置和申诉。每批功能上线时保持兼容和可回退。

## F5 — 自部署与 SDK

完成公开 Docker 部署、OAuth PKCE 接入指南、TypeScript SDK 稳定版、契约兼容测试和第三方示例；Python SDK 在出现真实使用需求时启动。

## F6 — 上线加固与 V1

完成安全评审、法律文本、隐私影响评估、容量压测、备份恢复演练、监控告警、事故预案和发布审查。只有完整社区范围与上线门槛全部通过后发布 V1。
