# MC Plan 宪法

状态：Accepted

版本：1.1.0

## 使命

MC Plan 是统一生态标准下持续扩展的 Minecraft AI 创作平台。皮肤生成是第一个纵向业务，不是平台边界。

## 不可破坏的原则

1. **独立交付**：Core、Community、Skin 及未来模块必须能够独立构建、部署、版本化和维护。
2. **禁止源码耦合**：仓库之间不得导入源码、共享数据库表或复制接口类型；只通过版本化 API、SDK、事件和标准协议协作。
3. **数据归属唯一**：每类数据只能有一个权威服务。其他服务保存引用、缓存或明确标识的快照。
4. **标准优先**：身份使用 OIDC/OAuth，公共接口使用 OpenAPI/JSON Schema，文件存储使用 S3 兼容抽象。
5. **渐进交付**：始终保持一条可运行的纵向链路；正式版本的完整范围不因分阶段而缩水。
6. **隐私真实**：对外说明必须与实际数据处理一致。无法明确用途、期限和删除方式的数据不得收集。
7. **开源可用**：公开仓库不能依赖私有源码才能完成其声明的独立功能。
8. **决策可追溯**：影响多个仓库或公共契约的选择必须用 ADR 记录原因、代价和变更条件。
9. **主方向有界**：每个写工作流必须有唯一主仓库和显式锁；默认最多两个可写辅助仓库，不得依赖会话记忆维持范围。

## 决策优先级

出现冲突时依次遵循：法律与安全要求、本文、已接受 ADR、公共契约、仓库局部文档、临时任务说明。更高层变化必须通过显式评审，不得用实现细节绕过。

## 修改规则

宪法修改必须新建 ADR，说明受影响仓库、迁移计划、兼容策略和回退方法。禁止只修改本文而不记录原因。
