# 资源与社区模型

## 通用资源边界

Community 拥有所有公开作品。通用模型只抽象已经明确的共同事实，类型专用字段由版本化 JSON Schema 校验。

- `Resource`：稳定作品标识、类型、作者、生命周期状态、当前版本。
- `ResourceVersion`：不可变版本号、类型 Schema 版本、说明、发布时间。
- `ResourceFile`：文件角色、对象键、大小、媒体类型、哈希与校验状态。
- `LicenseSnapshot`：发布时使用的许可 ID、版本、署名要求和文本摘要。
- `ResourceRelation`：未来表达合集、依赖或派生关系；首版不提前定义 Mod/地图语义。

首发只允许 `type=skin`。Skin 类型元数据至少区分 Steve/Alex 模型、64×64 尺寸和双层支持；其他类型必须通过 ADR 和新 Schema 启用。

## 生命周期

```text
uploading -> validating -> pending_moderation -> published
                              |                  |
                              v                  v
                           rejected          unpublished
```

状态变化只能通过领域操作发生，并记录操作者、原因和时间。公开列表只返回 `published`。

## 社区首发能力

- 浏览：最新、关注、热门、标签、搜索、作者页、详情、版本和下载。
- 互动：点赞、收藏、评论、关注；每项写操作均支持幂等和撤销。
- 分发：规则型热度与推荐，公开可解释的时间衰减和反作弊基础规则。
- 通知：站内通知为主；安全类邮件由身份系统发送，社交邮件默认关闭。
- 治理：举报、机器审核、管理员处置、申诉、封禁与审计。

搜索首版使用 PostgreSQL 全文检索与索引，不引入独立搜索集群。推荐首版是规则型而非机器学习个性化。

## 许可政策

默认政策要求下游使用者注明原作者与 MC Plan 社区；作者可以选择批准的其他许可或提供单独豁免。每个版本保存不可变许可快照。该政策不是正式法律文本，正式上线前必须完成专业法律审核。
