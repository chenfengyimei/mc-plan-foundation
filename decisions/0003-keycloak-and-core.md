# ADR-0003：Keycloak 负责凭证，Core 负责业务身份

状态：Accepted
日期：2026-10-01

## 背景

自研密码、会话、邮箱验证和 OIDC 会引入高安全风险；同时 MC Plan 不能让业务主键绑定某个身份产品。

## 决策

Keycloak 处理凭证、会话和 OIDC。Core 以 `(issuer, subject)` 映射自己的用户 ID，并拥有资料、角色、开发者应用、积分和审计。

## 后果

需要部署与升级 Keycloak，并维护身份映射；业务服务不接触密码，可以使用标准 OIDC，未来可迁移身份提供者。

## 变更条件

Keycloak 无法满足已验证的地区、合规或可用性要求时，可替换身份提供者，但必须保持 OIDC 契约和 Core 用户 ID 稳定。
