# ADR-0015：皮肤视觉验收路线改选概念图管线（Q-001 基准结论落档）

状态：Accepted
日期：2026-10-13

## 背景

Q-001（正式 AI 生成提供商）自 F1 起以受控付费基准推进。决策路径与证据链如下，每一步均有记录/提交/日志出处：

- 2026-10-07 项目所有者决策 Q-001=B：授权智谱 GLM 付费 key 做受控基准（凭据只经 gitignored `mc-plan-skin/apps/worker/.env` 注入，绝不入 Git/日志；受控生成预算双重口径如实计数）。
- 2026-10-10/12 受控付费基准（`MCP-F1-SKIN-008` 基准台账）：**flash 档（glm-5.3-flash）在 v4 逐像素蓝图协议第 1-6 轮守门规格下证伪**——同一 flash+high 配置四次成功生成评分 1.5/2/4/1（高方差抽卡），最佳 #5 候选 0a7c72e0 仅 4/10 且同协议直接回归暗噪点、不可复现。证据：`/Users/chenfeng/.codex/outputs/mc-skin008-benchmark-20261010/`（四张候选 PNG 与基准报告）。
- 2026-10-12 所有者三选一先选 a：旗舰 `glm-5.3` × 新协议（第 4-6 轮）受控重测（预算 ≤5 次受控生成、双重口径计数）。01 号会话接管执行第 7 轮探测：两把所有者交付 key（2026-10-10 与 2026-10-12 各一）对旗舰 `glm-5.3` 均返回 `error 1113 余额不足或无可用资源包`，**旗舰×新协议组合未获测试窗口**；受控生成预算 5/5 完整保留（原始 LLM 调用口径本轮仅 1 次轻量探测，如实入账）。证据：`/Users/chenfeng/.codex/outputs/mc-skin008-flagship-20261012/SESSION-LOG.md`。
- 2026-10-12 第 7 轮探测后，所有者同会话**改选概念图管线**并直接派发 02 号概念桥接提示词， 路径被取代。`MCP-F1-SKIN-008` 以**工程范围收官**关闭（离线工作台、skin.yaml 0.1.0-alpha.1 生产者、v4 协议与确定性渲染器全部完成并经全量门禁；**不声称任何候选通过所有者视觉验收**），视觉验收连同“文本直出 v4”与“概念图→视觉→v4”两路线可比指标口径移交 `MCP-F1-SKIN-009`。证据：`memory/workstreams/completed/MCP-F1-SKIN-008.json`、mc-plan-skin main `8932395`（=origin/main，远端 feat 分支已删除）。

## 决策

- **皮肤视觉验收与图像生成评估路线改选概念图管线**：概念图生成 → 视觉模型读图提取 → v4 逐像素蓝图 → 现有确定性渲染器，由 `MCP-F1-SKIN-009` 以厂商中立方式承接（fake|llm|image Provider 类型注册、图像生成客户端与视觉提取客户端两个注入式抽象、同一 ProviderAdapter 接缝下可插拔互换）。
- **正式 AI 生成提供商（Q-001 厂商绑定）保持未决**：`MCP-F1-SKIN-009` 记录明确“Q-001 基准 ADR 决定前不绑定任何正式厂商，生产环境继续拒绝非基准适配器实例化”；厂商绑定待概念图管线受控基准产生候选并通过所有者视觉验收后，由新 ADR 决定。
- **flash 档证伪记录在案**：glm-5.3-flash 不作为直出 v4 路线的正式档位结论依据；旗舰 glm-5.3 因交付 key 无配额未获测试窗口，对其质量不作任何结论。
- **SKIN-008 收官定性**：仅声明工程范围交付，不构成视觉验收通过；受控生成预算从未耗尽（≤10 后设 ≤5，全部如实入账）。

## 后果

- Q-001 在 `memory/open-questions.md` 中保持开放，行内注记本 ADR 与 2026-10-12 路线决策；任何文件不得提前写入厂商绑定值。
- `MCP-F1-SKIN-009` 承接视觉验收门槛与两路线可比指标口径（有效皮肤率/编辑一致性/延迟/成本/地区与数据条款）；其实施、基准与厂商决策另循所有者授权，不在本 ADR 内决定。
- F1 里程碑按所有者 2026-10-13 实答落档为“工程面完成，正式收官待 SKIN-009 视觉验收通过”（见 `MCP-F1-FOUNDATION-016`）。
- 未迁移事项注记：Q-011（3D 预览库）实践中已按第一方 CSS 3D 执行（SKIN-008 交付），正式决议仍归 Skin 线；Q-012（结构化创作意图字段）仍开放（F3 前）。

## 变更条件

- 概念图管线受控基准产生候选并通过所有者视觉验收后，由新 ADR 决定正式厂商绑定；供应商替换或多供应商策略同样须新 ADR。
- 若所有者获得含旗舰配额的 key 并要求重测，按新的受控基准任务执行，不回溯本决策；本 ADR 记录的证伪与未测结论以当时的探测台账为准。
