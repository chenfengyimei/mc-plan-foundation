# ADR-0014：启动 Community 本地资源工程，保留审核与正式发布门槛

状态：Accepted
日期：2026-10-12

## 背景与授权

项目所有者要求“完成整个项目的收尾以及开发，优先完成 core 与社区内容”。Core 的 F1 本地身份、资料、授权、权益、积分原语、审计、事件和指标已形成真实验收闭环；CORE-012 复验并修复了并发发布的提交顺序漏洞。OPS-001/002/003 的真实身份、本地邮件与恢复证据仍在 main 可达。根据 ADR-0013，本地阶段不等待生产采购。公开积分回退、奖励数值与额外会话价格仍按 Q-003/Q-013 门槛处理，不把内部账本原语升格为已实现的产品计费。

## 决策

全局开发进入 F2 的本地资源工程。先建立 Community 预发布契约，再实现独立 NestJS/PostgreSQL、S3 兼容上传、真实 PNG 验证、不可变版本与许可快照、资源查询、受控下载和保留清理。

- 身份由已验证用户令牌与 Core 公共 API 解析；Community 不保存密码、邮箱或身份映射，只保存不透明用户 ID，无跨服务外键。
- 上传只写隔离私有前缀；预签名 URL 短期有效，明确限制大小和哈希。完成确认必须读取真实字节，校验大小、SHA-256、PNG 解码、64×64 布局与模型语义，再把已验证字节封存到客户端不可写的对象键。源上传的后续覆盖不能改变封存文件。
- 版本与许可快照创建后不可改写；许可由运行配置提供显式批准清单与原文哈希，不代填 Q-002 的正式法律文本。自动化夹具标明测试许可。
- 发布需独立审核放行；上传或调用方的审核声明不能代替 Community 决定。未配置提供商、超时或失败时保持待审，无静默放行。Q-009 仍未决，正式本地发布/预发布前由所有者确定方案。
- 外部对象访问与数据库事务之间的失败通过幂等封存、私有对象清理和可恢复任务处理；数据库是归属、状态、幂等与审计的真相，不依赖进程内锁。
- 公开查询仅显示 published。所有文件下载经过 Community 的即时可见性检查和安全响应头，禁止签发可绕过下架的长期公开对象 URL。
- 下架为终态：立即停止公开查询与新下载，七天后清理对象；备份最长三十天的淘汰与恢复前删除清单重放仍属于 Ops 真实演练门槛，不以本地 API 测试冒充通过。
- F4 社区批次的完整范围保留；F2 可运行、F3 可集成后依次推进。Q-008/Q-010 在推荐/管理实现前仍须裁决。

## 后果与回退

Community 不再停留在“禁止业务代码”的 F0 阶段，但本 ADR 不批准正式审核供应商、管理权限、生产采购、远端推送或上线。未通过审核的资源始终不可公开。契约仍为预发布版本，SDK 仅暴露有生产者证据的操作。

工程回退使用独立应用镜像与前向兼容迁移；禁止删除 Core 或 Skin 数据，禁止接管 SKIN-008 的锁。若审核方案、许可或备份门槛未满足，记录缺口并保持相应发布门槛关闭，其他工程验收可以继续。
