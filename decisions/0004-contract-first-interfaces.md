# ADR-0004：公共接口采用契约优先与版本化 SDK

状态：Accepted
日期：2026-10-01

## 背景

多个独立仓库若各自复制类型，会产生不可见的漂移并破坏第三方接入。

## 决策

公共 HTTP API 使用 OpenAPI 3.1，数据与事件使用 JSON Schema。契约在 `mc-plan-contracts` 中先行评审并发布，TypeScript SDK 从契约生成或验证，不手工复制模型。

## 后果

跨仓变更多一个发布步骤，但兼容性可自动检查。未知业务字段不能为了填满 Schema 而提前发明。

## 变更条件

若某协议无法表达已确认需求，可新增协议形式，但必须保留同等版本、验证和所有权规则。
