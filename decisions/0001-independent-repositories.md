# ADR-0001：采用六个并列独立仓库

状态：Accepted
日期：2026-10-01

## 背景

MC Plan 需要独立开源 Skin 与公共契约，同时让 Core、Community 和生产运维保持私有，并支持各模块独立部署。

## 决策

工作区根目录不建立父级 Git 仓库，建立 Foundation、Contracts、Core、Community、Skin、Ops 六个并列仓库。仓库通过发布的契约、SDK、协议和文档协作，不共享源码或数据库。

## 后果

独立发布和开源边界清楚，但跨仓变更需要兼容性矩阵、追踪 ID 和明确合并顺序。Foundation 保存组合状态，Contracts 保存接口真相。

## 变更条件

只有当多个仓库无法独立交付且长期重复成本被真实数据证明高于隔离收益时，才评估合并；便利性本身不足以推翻本决策。
