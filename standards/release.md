# 发布标准

## 版本

公共 Contracts/SDK 使用 Semantic Versioning。私有服务也使用可追溯版本和不可变镜像标签，禁止生产环境使用 `latest`。

## 发布门槛

- 契约、实现、迁移、配置、监控、运行手册和回退计划一致。
- 测试、依赖扫描、镜像扫描、契约兼容检查和数据保留检查通过。
- 新配置有安全默认值，旧环境缺少配置时不会静默采用危险行为。
- 变更记录说明用户影响、运维动作、破坏性变化和回退限制。

## 发布方式

优先滚动或蓝绿发布。数据库变化采用向前兼容阶段，先部署可兼容旧结构的应用，再迁移数据，最后在观察期后收缩旧结构。

紧急回退不能恢复已撤销的安全策略、丢弃新格式数据或重复积分操作；这些情况使用前向修复。
