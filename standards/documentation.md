# 文档标准

- 正文以简体中文为主；代码标识、API、文件名、错误码和稳定技术术语使用英文。
- 文档开头说明目的、状态和适用范围；不确定内容明确标注 Owner、决策门槛和最迟决策点。
- 长期结论写入文档或 ADR，具体工作写入 GitHub Issue/PR，接口细节写入 Contracts，禁止复制形成多个真相。
- 使用相对链接连接仓库内文档；跨仓链接在正式 GitHub URL 确定前使用仓库名和路径，不伪造地址。
- 示例不得包含真实域名、密钥、邮箱、用户数据或生产资源 ID。
- 架构图优先使用文本或 Mermaid，并与正文表达相同边界。
- 每次文档变更检查断链、术语、状态、所有者和相关 ADR。
