# 数据库标准

## 所有权与隔离

- Keycloak、Core、Community、Skin 使用独立数据库和数据库用户。
- 可以共享 PostgreSQL 集群，但禁止跨数据库查询、跨服务外键和共享写入账号。
- 只有拥有数据的服务执行迁移、备份验证和保留任务。

## 建模

- 主键为不透明稳定 ID；跨服务只保存对方 ID，不建立数据库外键。
- 所有可变业务表包含创建与更新时间；需要审计的状态变化使用追加记录。
- 账本、许可快照、已发布版本和审计事件不可原地改写。
- JSON 字段必须有版本化 Schema 和明确查询策略，不能代替所有关系建模。
- 软删除只用于确有恢复、申诉或合规需求的实体，并规定硬删除期限。

## 迁移

- 迁移必须向前可部署，优先 expand/migrate/contract 三阶段。
- 部署包不得在多个实例启动时无协调地自动执行生产迁移。
- 大表修改、回填和索引创建要有锁影响评估与中断恢复方案。
- 每次发布前验证从上一受支持版本升级，并定期验证备份恢复而非只验证备份任务成功。
