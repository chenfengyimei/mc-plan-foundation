# 安全标准

## 基线

- 默认拒绝、最小权限、密钥分离、短期令牌和可审计变更。
- 密钥只进入受控运行环境或密钥管理系统，不进入 Git、镜像层、客户端包、日志或文档示例。
- 管理、审核、用户和服务身份使用不同角色与凭证。

## 输入与文件

- 在服务边界验证请求体、路径、查询、回调 URL 和对象存储元数据。
- 上传使用随机对象键和预签名短期 URL；完成后重新读取实际大小、媒体类型和哈希。
- PNG 必须实际解码和结构验证，不信任扩展名或浏览器声明。
- 下载使用受控响应头，用户内容不得在应用主域获得可执行上下文。

## Web 与 API

- 生产环境仅 HTTPS，设置安全 Cookie、CSRF 防护、CSP、合理 CORS 和请求尺寸限制。
- 对登录、生成、上传、互动、举报和积分操作分别限流。
- SSRF 风险的 URL 获取使用协议、域名和地址范围白名单，禁止访问云元数据地址。
- 所有依赖与容器镜像定期扫描，严重漏洞有明确修复时限。

## 审核与事故

- 高风险设计和认证、积分、上传、权限变更必须进行威胁建模和安全评审。
- 日志包含 trace ID 和动作结果，不记录机密内容。
- 建立密钥轮换、用户会话撤销、内容紧急下架、数据泄露响应和通知流程。
